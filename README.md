# OAD concept redesign

This is an unofficial concept redesign of the IAU Office of Astronomy for Development website, [astro4dev.org](https://astro4dev.org/). It is a learning project and is not affiliated with, or endorsed by, the IAU Office of Astronomy for Development.

The OAD name, logo, brand assets and OAD-related content belong to the IAU Office of Astronomy for Development and the International Astronomical Union. This project does not represent the official OAD website.

## Media

The photos and Milky Way video used in the concept come from the sources recorded in [credits.md](credits.md). Please check the credit and licence information before reusing any asset.

## Run locally

This is a plain HTML, CSS and JavaScript project with no build step.

1. Open the project folder in VS Code.
2. Install the **Live Server** extension if it is not already installed.
3. Open `index.html`.
4. Right-click the file and choose **Open with Live Server**.

The site should open at a local address such as `http://127.0.0.1:5500/`. The project folder should be opened as the workspace so relative asset paths work correctly.
